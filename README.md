# Infotact---Project-2---Group-12

This repository is created as part of Infotact Solutions second month project - EchoChain

Problem Statement: Manufacturers track products rigorously until the point of sale. Post-sale, the product's lifecycle becomes a data blind spot. This makes it impossible to measure true environmental impact, landfill diversion, or the potential for profitable refurbishment.

Use Case: A Sustainability Executive opens EchoChain. The system has scraped secondary market sites (like eBay) and joined that data with internal manufacturing Bills of Materials (BOM). The dashboard reveals a high "Circularity Score" for a specific laptop model—showing that while its motherboard frequently fails (warranty data), its display holds high resale value on eBay, prompting a strategic buy-back and refurbishment program.

Sharanya responsibilities (tech stack): Web Scraping Infrastructure (Scrapy), Data Lakehouse (Databricks & Delta Lake), Big Data Processing (PySpark)
