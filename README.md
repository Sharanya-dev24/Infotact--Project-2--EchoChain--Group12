# EchoChain – Data Analytics & Power BI

## 📌 Project Overview

EchoChain is a data analytics project designed to transform raw operational data into meaningful business insights using a modern data engineering and analytics workflow.

The project uses a layered data architecture where data is processed through **Bronze, Silver, and Gold layers** before being consumed for analytics and visualization.

## 🏗️ Technology Stack

- Python
- SQL
- Databricks
- Delta Lake
- dbt
- Power BI
- Git & GitHub
